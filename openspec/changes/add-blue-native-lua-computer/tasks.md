# Tasks

Its 27/37 completed tasks and failed performance gates are historical experimental evidence, not completion of the approved event-driven shell. Preserve existing experiment code/tests and `docs/NATIVE_RUNTIME.md`; no removal is authorized by this revision. All tasks below require verification against the new shell architecture before checking them off.
